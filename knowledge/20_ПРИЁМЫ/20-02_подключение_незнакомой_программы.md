# Подключение новой программы

## Шаги
1. **Запуск**: `d.launch([...])`. Ошибка 740 — нужны права
   ([30-06](../30_ГРАБЛИ/30-06_повышенные_права_ошибка_740.md)). Если
   программа порождает другой процесс — искать окно по классу/заголовку.
2. **Окно**: `d.wait_window(cls=..., title=..., min_size=(300, 200))`.
   Класс окна — из `[w.cls for w in d.windows()]`. Диалоги: `d.dialogs()` —
   любое неожиданное окно «Ошибка/Лицензия/Обновление» — остановиться и
   прочитать (`dump`), не нажимать вслепую.
3. **Разведка**: `print("\n".join(w.dump()))` — классы и id элементов.
   Стандартные: `Edit`, `Button`, `ComboBox`, `SysTreeView32`,
   `SysListView32`, `SysTabControl32`, `msctls_statusbar32`.
   Нестандартные панели (BCG, MFC, Qt) держат стандартные элементы
   внутри — искать `find_all(cls="ComboBox")`.
4. **Одно действие** (`controls.*`) — и **проверка** тем, что программа
   отдаёт: `get_text`, выбранный узел, `tree_is_expanded`, состояние
   полосы прокрутки; затем снимок.
5. **Закрытие**: корректное (команда программы, например, quit через её API),
   затем `with` завершит остатки.

## Чего не делать
* Не менять настройки программы человека, не открывать его файлы:
  работать на копии данных ([20-03](20-03_безопасность_человека.md)).
* Не использовать координаты клика, если есть сообщение элементу
  (`button_click`, `combo_select`, `tree_select`) — координаты хрупки.
* Не ждать `time.sleep(10)` вслепую: ждать признак (`wait_window`, чтение
  состояния).

## Чем подтверждено
Три программы подключены по схеме без правок библиотеки.
