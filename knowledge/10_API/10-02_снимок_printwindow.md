# Снимок окна

## Как правильно
```python
img = w.capture()                      # весь прямоугольник окна, с рамкой
img.save("shot.png")                   # PNG (zlib), .bmp тоже
part = img.crop((x0, y0, x1, y1))      # пиксели снимка
img.is_blank()                         # все пиксели одного цвета
img.dark_fraction()                    # доля тёмных пикселей (есть текст)
img.to_pil()                           # если установлен Pillow
```
* Размер снимка = размер окна (`w.rect`). Хотите больше деталей — растяните
  окно (`w.set_rect`), но не выше `max_window_size()` ([30-05](../30_ГРАБЛИ/30-05_размер_окна_ограничен.md)).
* `Window.capture()` сам перерисовывает окно (`redraw()`) перед снимком;
  после изменения размера/масштаба/открытия документа всё равно выдержать
  паузу 0,5–1,5 с, пока программа дорисует ([30-09](../30_ГРАБЛИ/30-09_развёрнутое_окно_не_перерисовывается_при_растяжении.md)).

## Что внутри
`CreateDIBSection` 32 бита, сверху вниз (`biHeight < 0`),
`PrintWindow(hwnd, dc, 2)`. Если флаг 2 не принят — `CaptureError`.

## Не проверено
* Окна, которые рисует видеокарта в обход GDI (полноэкранные DirectX/OpenGL,
  Chromium/Electron с GPU), могут сниматься чёрными. Проверять
  `is_blank()`; запуск таких программ с `--disable-gpu` — не проверен.
* Масштаб DPI > 100 %: размеры в снимке — физические пиксели; не проверялось.

## Как неправильно
* `BitBlt` с `GetDC(hwnd)` для окна, которое не на видимом столе: вернёт
  мусор/пустоту (не проверено отдельно, PrintWindow проверен).
* Уводить окно за экран (-32000) ради «невидимости» — [30-04](../30_ГРАБЛИ/30-04_окно_за_экраном_перерисовывается_частично.md).
