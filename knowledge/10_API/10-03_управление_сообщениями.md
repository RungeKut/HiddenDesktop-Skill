# Управление без мыши и клавиатуры

| Задача | Функция hdkit | Как работает |
|---|---|---|
| Прочитать/записать текст поля | `controls.get_text/set_text` | WM_GETTEXT/WM_SETTEXT с тайм-аутом |
| Набрать текст | `controls.type_text` | WM_CHAR по символу (окну с фокусом ввода программы) |
| Enter/Esc/Tab/стрелки | `controls.press` | WM_KEYDOWN/WM_KEYUP (Post) |
| Нажать кнопку | `controls.button_click` | BM_CLICK |
| Клик/двойной клик по координатам | `controls.click` | Post WM_LBUTTONDOWN/UP/DBLCLK с паузами |
| Выпадающий список | `combo_items`, `combo_select` | CB_*; затем WM_COMMAND(CBN_SELENDOK) родителю |
| Прокрутка | `scroll`, `scroll_info` | WM_VSCROLL/WM_HSCROLL (SB_PAGEDOWN) окну |
| Дерево | `tree_path`, `tree_select`, `tree_expand`, `tree_item_rect`, `tree_open`, `tree_is_expanded` | TVM_*; прямоугольник — через `RemoteBuffer` |
| Структура в lParam | `controls.RemoteBuffer` | VirtualAllocEx/Read/WriteProcessMemory в процессе программы |
| Узнать, что есть в окне | `Window.dump()`, `find_all(cls=, title=, ctrl_id=)` | EnumChildWindows |

## Правила
1. **Чтение и ожидание — только `controls.send`** (SendMessageTimeout,
   SMTO_ABORTIFHUNG): зависшее окно вернёт `(False, 0)`, а не подвесит
   скрипт ([30-07](../30_ГРАБЛИ/30-07_зависание_и_остаточные_процессы.md)).
2. **Мышь — только Post.** SendMessage с WM_LBUTTONDOWN на дерево/список
   вешает программу в DragDetect ([30-01](../30_ГРАБЛИ/30-01_sendmessage_мыши_вешает_дерево.md)).
3. **Дескрипторы 64-битные** — только через `hdkit` (argtypes заданы)
   ([30-03](../30_ГРАБЛИ/30-03_64_битные_дескрипторы_обрезаются.md)).
4. Сообщение не гарантирует действия: программа может отфильтровать
   «чужой» ввод. Результат всегда проверять — прочитать состояние (текст,
   выбранный узел, раскрытие) или снять окно.
5. Нестандартные элементы (BCG/MFC-панели, Qt, WPF, Electron) могут не
   отвечать на стандартные сообщения: смотреть `dump()`, искать стандартный
   элемент внутри (например `ComboBox` внутри панели инструментов).

## Как узнать id и класс элемента
`print("\n".join(w.dump()))` — класс, id, заголовок, прямоугольник всех
вложенных окон. `ctrl_id` — id в родителе (его же ждёт WM_COMMAND).
