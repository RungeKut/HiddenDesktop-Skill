# Скрытый рабочий стол

## Что это
Рабочий стол (desktop) — объект сессии Windows, на котором живут окна.
Человек видит и управляет только «входным» (input) столом. CreateDesktopW
создаёт второй стол в той же сессии и пользователе; его окон человек не
видит, фокус и ввод на него не идут.

## Как правильно
```python
from hdkit import HiddenDesktop
with HiddenDesktop() as d:                 # CreateDesktopW
    p = d.launch([r"C:\Windows\System32\notepad.exe"])   # lpDesktop=имя стола
    w = d.wait_window(pid=p.pid, min_size=(300, 200))
    ...
# выход из with: процессы стола завершены, стол закрыт
```
* `launch` принимает строку или список (кавычки расставляются сами).
* Дочерние процессы наследуют стол. Программа, у которой «главное окно»
  создаёт другой процесс (лаунчер), показывает окно на этом же столе, но
  `pid` окна другой — искать окно по классу/заголовку, а не по pid.
* `wait_window` ждёт устойчивый размер: многие программы сначала создают
  заготовку 40x40 и только потом собирают окно.
* Стол живёт, пока жив хотя бы один процесс на нём или не закрыт дескриптор.
  `close()` завершает процессы запуска и владельцев окон стола, потом
  закрывает стол.

## Как неправильно
* Запустить программу обычным `subprocess.Popen`/`os.startfile` — окно
  появится у человека и может перехватить фокус.
* Не закрывать стол: процессы остаются без видимых окон, их находят только
  в диспетчере задач.
* Передать `lpDesktop` строкой Python без удержания буфера — в `launch`
  буфер хранится в объекте стола.
