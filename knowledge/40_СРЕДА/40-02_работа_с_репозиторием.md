# Работа с репозиторием

Набор — `https://github.com/RungeKut/HiddenDesktop-Skill`, ветка `main`.
**Порядок, обезличивание, стоп-лист, автор, соавторы, форк и разбор PR —
соседний скилл skill-skill, `knowledge/40_СРЕДА/40-02`.** Коротко: в начале
`git -C <корень> pull --rebase`; после правки `git diff` глазами →
`python tools/check_docs.py --project "<папка проекта>"` → `git add
<файлы>` → `git commit` → **`git push` сразу**.

## Обезличивание: окна программ

Кроме общего списка, в набор, текст коммита и PR не попадают:

* **названия, классы окон, заголовки и тексты закрытых программ**, с
  которыми работали, их меню и диалоги, имена проектов в заголовках окон;
* **снимки окон рабочих программ**: на картинке читаются имена и данные, а
  стоп-лист картинки не видит. Снимки живут во временной папке сессии или
  в `tests/vyvod/` (в `.gitignore`); примеры и тесты — только на Блокноте,
  msinfo32 и других программах из поставки Windows.

Остаётся: поведение Windows и WinAPI, вызовы `hdkit`, ловушки, примеры на
программах из поставки Windows и на отвлечённых окнах.

Папку проекта для стоп-слов можно запомнить для клона:
`git config hidden-desktop.project "<папка проекта>"` — её учитывают и
`check_docs.py`, и хук.
