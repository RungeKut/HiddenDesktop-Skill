# Установка

Репозиторий и есть папка скилла: `SKILL.md` лежит в корне, рядом `hdkit/`,
`tools/`, `knowledge/`. Имя папки — как `name` в `SKILL.md`.

```powershell
git clone https://github.com/RungeKut/HiddenDesktop-Kit.git "$env:USERPROFILE\.claude\skills\hidden-desktop"
cd "$env:USERPROFILE\.claude\skills\hidden-desktop"
git config core.hooksPath tools/hooks          # хук commit-msg (40-02)
git config user.name  "<публичное имя>"         # автор — для клона (40-02)
git config user.email "<публичный адрес>"
New-Item tools\stoplist.txt -ItemType File     # локальный стоп-лист (40-02)
python tools\check_docs.py                     # до «Расхождений нет»
```

Обновление — `git pull --rebase`; перезапуск агента не нужен. Kimi Code —
второй клон в `~\.kimi-code\skills\hidden-desktop` (не проверено).

## Подключение из другого набора

Наборы лежат рядом в одной папке скиллов; `hdkit` ищется по соседству:

```python
import os, sys
ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))  # корень своего набора
sys.path.insert(0, os.path.join(os.path.dirname(ROOT), "hidden-desktop"))
from hdkit import HiddenDesktop, controls
```

Глубину `dirname` подобрать под место файла в своём наборе (не проверено:
соседние наборы ещё не переведены).

## Зависимости
Только стандартная библиотека Python 3 (ctypes, zlib, struct).
Pillow — по желанию (`Image.to_pil()`); без него PNG пишется своим
кодом.

## Проверка
`python tests\test_notepad.py`, `python tests\test_tree.py` — все `OK`.
Запускаются на скрытом столе, человеку ничего не показывают.

## Ограничения среды
Windows 10/11, сессия пользователя (не служба: у служб свой стол и
другие права), Python 64-bit, программы без повышения прав.

## История

До 0.2.0 (2026-10-28): `tools/setup.ps1` создавал junction
`~\.claude\skills\hidden-desktop` → `<корень>\skill` и переменную
`HDKIT_HOME`. Отказались: переменная пережила перенос клона и указывала на
несуществующую папку — скилл молча терял `hdkit` и базу; по наблюдению
владельца, в некоторых средах вместо ссылки появлялась папка с одной копией
`SKILL.md`, без остального набора (не проверено).
