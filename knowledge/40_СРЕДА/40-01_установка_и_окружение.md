# Установка

Общий порядок (папка скиллов агента, хук, автор, стоп-лист, обновление) —
соседний скилл skill-skill, `knowledge/40_СРЕДА/40-01`. Для этого набора:

```bash
git clone https://github.com/RungeKut/HiddenDesktop-Skill.git "<папка скиллов>/hidden-desktop"
cd "<папка скиллов>/hidden-desktop"
git config core.hooksPath ../skill-skill/hooks
git config user.name  "<публичное имя>"
git config user.email "<публичный адрес>"
python tools/check_docs.py
```

Своего стоп-листа набору не нужно — хватает общего; при необходимости —
`tools/stoplist.txt` (локальный).

## Подключение из другого набора

`hdkit` ищется по соседству, переменные окружения не читаются:

```python
import os, sys
ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))  # корень своего набора
sys.path.insert(0, os.path.join(os.path.dirname(ROOT), "hidden-desktop"))
from hdkit import HiddenDesktop, controls
```

Глубину `dirname` подобрать под место файла в своём наборе (не проверено:
соседние наборы ещё не переведены).

## Зависимости

Только стандартная библиотека Python 3 (ctypes, zlib, struct). Pillow — по
желанию (`Image.to_pil()`); без него PNG пишется своим кодом.

## Проверка

`python tests/run_all.py` — `test_notepad.py`, `test_tree.py` и
`check_docs.py`. Тесты идут на скрытом столе, человеку ничего не
показывают.

## Ограничения среды

Windows 10/11, сессия пользователя (не служба: у служб свой стол и другие
права), Python 64-bit, программы без повышения прав (30-06).
