# Журнал изменений

Формат строки: дата — что изменилось — почему.

## 2026-10-14 — HiddenDesktop-Kit 0.1.0

Первая версия. Проверено на Windows 10 Pro 10.0.19045, Python 3.13 64-bit.

* **Библиотека `hdkit`**: `HiddenDesktop` (CreateDesktop, запуск на столе,
  поиск и ожидание окна, закрытие со всеми процессами), `Window` (чтение с
  тайм-аутом, потомки, дамп дерева, размер), `capture`/`Image` (PrintWindow,
  PNG без Pillow, вырезка, проверка на пустоту), `controls` (текст, кнопки,
  клавиши, клики PostMessage, выпадающие списки, прокрутка, деревья через
  память чужого процесса).
* **Утилита** `tools/hd.py`: запустить программу скрыто, снять окно, вывести
  дерево окон.
* **База знаний**: 10-01…10-03, 20-01…20-03, 30-01…30-08, 40-01. Главные
  находки: скрытый стол не перехватывает ввод; SendMessage мыши вешает дерево,
  нужен PostMessage; 64-битные дескрипторы без argtypes обрезаются; окно за
  экраном перерисовывается частично; предел размера окна MAXTRACK;
  программы с правами администратора не запускаются (740).
* **Проверки**: `tests/test_notepad.py` (в том числе: окна и фокус человека
  не изменились), `tests/test_tree.py`, `tools/check_docs.py`.
* `Window.set_rect` восстанавливает развёрнутое окно (SW_RESTORE),
  `Window.capture` перерисовывает окно перед снимком (30-09).
* Вынесено из работы над раскладкой блок-схем VisualState-Kit.
